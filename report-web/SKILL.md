# 网页版研报渲染

将任意 Markdown 研报转换为单文件自包含 HTML（零依赖，双击即可离线打开）。

## 能力

- 玻璃拟态暗色主题，带渐变光效与动画
- 自动提取指数涨跌、涨跌家数、领涨领跌板块、两融水平生成仪表盘
- 市场宽度环形图、行业横向条形图、关键指标卡片
- 数字滚动动画、滚动揭示、阅读进度条
- 侧边目录导航（支持高亮当前章节）
- 表格自动生成条形图

## 用法

```bash
python "<模块目录>/report-web/scripts/render_report.py" --input "<报告.md>" --output "<报告.html>" [--title "自定义标题"]
```

## 依赖

无。仅需 Python 3 标准库。
