# 个股机构级深度研报规范

## 文件命名

`深度研报_公司简称_YYYY-MM-DD.md`

例如：`深度研报_好想你_2026-08-25.md`

## 报告结构（固定章节顺序）

### 0. 标题与评级框（报告最开头）

标题示例：`# 深度研报（完整版）：好想你（002582.SZ）——披着红枣股外衣的准投资控股公司`

评级框（放在标题之后、核心判断之前）：

```
> **客观评级：增持 / 推荐（预期相对基准涨幅 +10%~20%）**
>
> 评级理由：……（结合核心逻辑、量化空间、确定性说明；给出上调/下调触发条件）
>
```

评级体系：

- 买入 / 强烈推荐：预期股价相对基准涨幅 20% 以上
- 增持 / 推荐：预期相对基准涨幅 10%~20%
- 持有 / 中性：预期相对基准涨跌幅 -10%~+10%
- 减持 / 回避：预期相对基准跌幅 10% 以上
- 卖出：预期相对基准跌幅更大，建议清仓

评级必须与后面的情景推演一致，并写明“为什么不是更高/更低评级”。

### 1. 核心判断（非共识）

- 一段话讲清“与市场一致预期不同”的核心观点。
- 明确：市场怎么想、我认为实际是什么、最重要的非共识机会在哪。
- 示例逻辑：SOTP 折价、双 Beta 已打满、二阶导标的、母公司订单折算等。

### 2. 基础版：五维度快览

每个维度都必须有数据、日期和解读：

1. 估值维度：现价、涨跌幅、总市值、PE（TTM/静态/动态）、PB、股息率、分红比例；PE 失真时要说明失真原因。
2. 财务维度：最新报告期营收/净利/扣非/毛利率/ROE/负债率/现金流；拆单季（Q1/Q2…）；说明一次性收益与质量。
3. 资金维度：主力净流入/流出、换手率、资金流入/流出额；结合筹码数据（获利盘、平均成本、90%/70% 成本区间、集中度）。
4. 技术维度：MA20/MA60、RSI、MACD；现价相对均线位置；短中期动能判断。
5. 消息与催化维度：最新公告、业绩、评级、订单、参股/投资、事件；注明来源与日期。

最后给一段“解读”：数据表面 vs 实质。

### 3. 产业链拆解

- 公司所处位置：上游 / 中游 / 下游，具体环节（品牌加工、酿造、系统集成等）。
- 产业链关键位置：真正的价值咽喉在哪（原料、品牌、老酒储备、设备、渠道、资本开支前置工程等）。
- 产业链最赚钱的环节：为什么赚钱、公司是否受益、公司在哪个环节。
- 特别指出“公司身份与产业链的连接点”（如中游加工商 + 下游渠道股东、母子公司分包关系）。

### 4. 政策链分析

- 政策方向：列出直接影响或间接影响公司的政策（产业政策、税收、监管、资本市场、区域、出海等）。
- 政策对公司影响有多大：
  - 量化（如税率差、贴息、订单规模、资本开支、补贴）；
  - 敏感度分级（高/中/低）；
  - 政策到期时间与尾部风险；
  - 区分“已在股价中反映”与“未反映”。

### 5. 非共识 α 观点

- 每条 α 用统一格式：
  - 市场怎么看；
  - 非共识点（正确但少有人这样定价）；
  - α 来源 / 兑现路径；
  - 证伪条件。
- 数量 2~4 条，宁缺毋滥，每条都要有数据或事件支撑，避免泛泛的“看好行业”。

### 6. 情景推演与关键变量

- 乐观 / 中性 / 悲观三档，每档给估值或价格区间与触发条件。
- 关键变量：订单、现金流、回款、参股公司股价、税率、大本营/全国化数据、产品动销等。
- 必须给出“看多确认”与“看多证伪”清单。

### 7. 风险提示（详细版）

按“多维度 + 量化 + 尾部情景 + 防御纪律”展开，通常 8~11 类：

- 投资收益集中度 / 订单折算 / 品类天花板 / 利润质量等“最核心风险”放最前。
- 每类风险给出：风险描述、量化冲击（如股价每跌 10% 影响多少）、触发信号。
- 尾部情景：最悲观情形下估值/股价的量化空间。
- 防御纪律：止损位、止盈位、仓位上限、加仓条件。

### 8. 文末

```
---

数据来源：同花顺问财、东方财富妙想、公开新闻。本报告不构成投资建议。
```

## 数据纪律

- 所有数据标注日期和来源；接口为空写“未取到”。
- 估值/财务/技术/筹码以最近交易日或指定日期为准，盘中数据需标注“盘中”。
- 涉及参股投资、母公司订单、税率等非共识论据，必须有公开新闻/公告/互动平台来源。
- 评级、目标价、止损止盈均为判断或示例参数，必须声明不构成投资建议。
- 禁止编造订单、业绩、股东、价格等数据。

## 抓取脚本产出（fetch_stock_data.ps1）

- `stocks_quote.json`：现价、涨跌幅、换手率、主力资金
- `stocks_valuation.json`：PE/PB/总市值/股息率
- `stocks_finance.json`、`stocks_ratios.json`：营收/净利/毛利/ROE/负债
- `stocks_tech.json`：MA20/MA60/RSI/MACD
- `stocks_chips.json`：获利盘、平均成本、成本区间、集中度
- `stocks_ratings.json`：机构评级
- `stocks_news.json`：公司新闻（news-search）
- `stocks_announcements.json`：公司公告
- `stocks_reports.json`：公司研报
- `mx\`：妙想备用数据（行情、财务、搜索）
