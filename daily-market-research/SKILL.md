# 每日市场研报

## 目标

生成两份 Markdown 研报：

1. `每日市场研报_YYYY-MM-DD.md`：基础每日研报。
2. `每日市场研报_YYYY-MM-DD_深度分析与标的策略.md`：深度分析 + 标的策略。

## 前置条件

- `IWENCAI_BASE_URL` 和 `IWENCAI_API_KEY` 已存在（Windows PowerShell profile 已配置）。
- `MX_APIKEY` 已存在（妙想备用数据源，Windows PowerShell profile 已配置）。
- Iwencai 技能已安装，默认技能根目录为 `D:\codex\研报\skills`，备用根目录为 `C:\Users\csy\.codex\skills`。
- 妙想技能已安装到 `C:\Users\csy\.codex\skills\mx-data`、`mx-search`、`mx-xuangu` 等。

## 工作流

1. 确定日期和输出目录。
   - 日期默认取当天，例如 `2026-08-05`。
   - 输出目录默认取 `D:\codex\研报`，也可使用当前工作区。

2. 抓取数据。
   - 运行：`powershell -ExecutionPolicy Bypass -File "<技能目录>\scripts\fetch_daily_data.ps1" -Workspace "D:\codex\研报"`
   - 脚本会把原始 JSON 保存到 `<Workspace>\data\<date>\`。
   - 脚本同时抓取两融水平（融资余额、融券余额、两融余额、融资净买入、融资买入额、融资余额环比，市场合计口径）、情绪数据（北向资金、市场宽度、连板/昨日涨停表现）和资金结构数据（超大单、大单、中单、小单、行业资金流入流出）。

3. 妙想备用抓取。
   - 若 Iwencai 返回配额不足、数据缺失或需要交叉验证，运行：
     `powershell -ExecutionPolicy Bypass -File "<技能目录>\scripts\fetch_miaoxiang_data.ps1" -Workspace "D:\codex\研报"`
   - 选定个股后可用 `-StockNames "股票A 股票B"` 让妙想补查个股数据。
   - 妙想结果保存在 `<Workspace>\data\<date>\mx\`。

4. 阅读原始数据。
   - 优先读取脚本生成的 JSON 文件。
   - 若关键字段缺失，用 `references/report_spec.md` 中的补充查询语句再查。

5. 动态选择板块和个股。
   - 板块必须由当日数据决定：行业涨跌幅、资金流向、政策催化、机构观点综合判断。
   - 市场驱动板块和政策驱动板块都必须有当日证据，不能默认沿用昨天的半导体、通信、医药、电网、核电、AI、消费。
   - 个股必须从当日扫描数据中筛选：涨幅居前、主力净流入、机构评级/金股、业绩或事件催化。
   - 禁止使用任何固定备选池，个股完全由当日扫描结果决定。
   - 每个板块从当日数据中选出 2-4 只最相关龙头股，并在深度研报的板块推荐中列出。

6. 生成基础研报。
   - 按 `references/report_spec.md` 的“基础研报”结构生成。
   - 必须包含模块十“情绪分析”、模块十一“两融水平及分析”和模块十二“资金分析”。
   - 两融水平及分析必须覆盖水平、边际、活跃度、杠杆结构、信号解读、去杠杆风险六个维度，并使用沪深两市合计口径。
   - 政策与要闻必须逐条包含“内容解读”和“影响分析”，先解释事件内容，再分析市场影响。

7. 生成深度分析与标的策略。
   - 按 `references/report_spec.md` 的“深度分析与标的策略”结构生成。
   - 每只个股必须包含：股票类型、估值、财务、资金、技术、消息催化、短中长期、止损、止盈、风险。
   - 板块推荐必须区分“市场驱动板块”和“政策驱动板块”。
   - 政策与要闻章节与基础研报保持一致，每一条都必须有“内容解读”和“影响分析”。
   - 每个板块下方列出 2-4 只龙头股，且这些龙头股必须全部进入“个股深度分析”并逐一完整分析。
   - “情绪与资金分析”章节必须包含“两融水平及分析”小节，覆盖两融余额、融资余额、融券余额、融资净买入、融资买入额占成交额比例、杠杆率与去杠杆风险。
   - 报告开头或板块部分写明“本次选择该板块/个股的数据依据”，证明不是沿用旧名单。

8. 验证。
   - 两份文件都存在于输出目录。
   - 每个章节都有风险提示。
   - 基础版必须包含“非共识 α 观点”章节，深度版必须包含“非共识 α 观点”章节；每条非共识观点都要包含“市场一致预期 / 非共识点 / α 来源与兑现路径 / 证伪条件”。
   - 模块十（情绪分析）、模块十一（两融水平及分析）和模块十二（资金分析）必须使用接口实际返回的数据；两融数据使用沪深两市合计口径，机构资金、主力资金、大户资金、散户资金需标注近似口径。
   - 未取到的数据必须明确标注，禁止编造。
   - 两融水平及分析必须包含水平、边际、活跃度、杠杆结构、信号解读、去杠杆风险六个维度，缺数据写“未取到”。
   - 对比上一交易日报告，确认板块和个股发生变化且有新证据，或说明为何继续保留。
   - 验证板块推荐中列出的龙头股是否全部出现在个股深度分析中，且每只都包含完整分析。
   - 验证政策与要闻章节是否逐条包含“内容解读”和“影响分析”。
   - 文末注明“数据来源：同花顺问财”和“不构成投资建议”。

## 数据纪律

- 只使用接口实际返回的数据。
- 接口为空时写明“未取到”，不要用推测补数。
- 指数、个股、ETF、宏观、汇率等数据要标注日期。
- 止盈止损均为示例风控参数，不是保证。
- 涉及评级、金股、研报观点时注明机构和日期。
- 板块和个股不是固定名单，必须以当日数据为准动态调整。
- 妙想数据作为 Iwencai 的备用或交叉验证来源，使用时要标注“数据来源：东方财富妙想”。
- 情绪指标包括融资融券余额、北向资金、上涨家数占比、涨停跌停家数、连板/昨日涨停表现、换手率；取不到时写“未取到”。
- 两融水平必须使用沪深两市合计口径（margin_level.json / margin_flow.json / margin_change.json），个股级两融数据不可充当市场两融水平；妙想近5日趋势（mx_data_margin.log）作交叉验证。
- 资金结构使用近似口径：机构资金参考超大单，主力资金参考超大单+大单，大户资金参考大单，散户资金参考中单+小单；必须注明这是近似口径。
